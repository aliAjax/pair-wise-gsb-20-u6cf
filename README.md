# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库——已接入**可追溯验收流程**：

```
样本 Sample
  └─ 观察记录 ObservationRecord（离线可补录，IndexedDB 本地持久化）
       └─ 回网后按玻片编号核对中心实验室接收回执 LabReceipt
            ├─ 拒收 / 编号被别的玻片占用 / 双方字段不符 → 停在「待核区」并列双方值
            └─ 接收且一致 → 已核对
                 └─ 测量结论有效（依赖版本未变）→ 固化为不可变「已验收快照」
```

## 验收规则

- **离线补录**：断网时录入只写本地并入待同步队列，回网后逐条按玻片编号换取中心回执。
- **待核区**：回执拒收、玻片编号已被别的玻片占用、或回执字段与本地对不上时，记录停在待核区，
  界面列出「本地值 vs 中心值」，可就地更正并重新排队核对。
- **依赖版本**：测量结论同时引用染色批次版本与标尺版本；任一升版后，未验收记录的结论标记为
  「失效待重算」，重算前不能进入已验收快照；已固化的快照结论与版本号不受影响。
- **并发**：两名镜检员同时提交同一玻片编号时，中心登记册原子占位，只有一条拿到接收回执，
  另一条落入待核区（带占用方记录/建档号）。
- **写入中断**：顺序同步、逐条立即落库；中断后已完成条目不丢、不重放，仅未完成部分重试；
  中心已落库但响应丢失时，重试按幂等返回原回执，不会重复建档。

## 技术栈

React 19 + Vite + TypeScript + CSS，本地持久化使用 IndexedDB。

- `src/types.ts`：领域模型（样本 / 记录 / 回执 / 快照 / 染色批次 / 标尺）
- `src/domain/engine.ts`：纯规则（回执核对、失效判定、快照门槛、待同步选择器）
- `src/services/centralLab.ts`：中心实验室模拟（原子占位、拒收、幂等重放、故障注入）
- `src/services/storage.ts`：IndexedDB 持久化
- `src/state/store.tsx`：reducer 与顺序同步循环（逐条落库、崩溃恢复）

页面工具栏可直接演示：断网补录、回网核对、并发抢同一编号、注入写入中断；
